Mon site statique est en ligne

Ce site est hébergé sur un serveur Linux avec Nginx et déployé automatiquement à l'aide de rsync.

Découvrir le projet

À propos du projet

Linux

Le serveur distant fonctionne sous Linux et est administré à travers une connexion SSH.

Nginx

Nginx reçoit les requêtes HTTP et retourne les fichiers statiques du site.

rsync

Les fichiers locaux sont synchronisés avec le serveur distant grâce à un script de déploiement.
